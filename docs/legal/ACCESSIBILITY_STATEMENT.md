# LeetAlly Accessibility Statement

**Effective date:** 17 August 2026

LeetAlly aims to make its website and browser extension usable with keyboards,
screen readers, browser zoom, reduced-motion preferences and high-contrast
display settings. The product uses semantic headings and labels, visible focus
states, text alternatives for meaningful images, status messages that can be
announced by assistive technology, and reduced-motion fallbacks.

LeetAlly is working toward WCAG 2.2 Level AA as its engineering target. This is
an objective, not a certification of full conformance. Automated checks alone
cannot establish accessibility, so the public release still requires manual
keyboard, screen-reader, zoom, contrast and voice-feature testing.

To report an accessibility barrier or request a reasonable alternative, email
**watershaper9.1@gmail.com** with the page, feature, assistive technology and
problem encountered. We will acknowledge the report and work toward a practical
resolution.
