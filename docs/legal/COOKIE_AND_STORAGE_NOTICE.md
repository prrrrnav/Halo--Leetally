# LeetAlly Cookie and Device Storage Notice

**Effective date:** 17 August 2026
**Version:** 2026-08-17

LeetAlly uses browser storage only for functions needed to provide the website
and extension: maintaining a Supabase authentication session, preventing abuse,
remembering preferences, saving local preparation progress and synchronizing
progress when a user signs in.

LeetAlly does not currently use advertising cookies, cross-site tracking pixels
or non-essential analytics cookies. Because current storage is necessary for
features requested by the user, it cannot be disabled without signing out,
losing local preferences or preventing the relevant feature from working.

Google, Cashfree and other providers may use their own storage when a user
chooses to visit or interact with those providers. Their policies control that
independent activity.

If LeetAlly later adds non-essential analytics, advertising or personalization
storage, it must update this notice and deploy a region-appropriate consent
control before activating that storage where consent is required.
