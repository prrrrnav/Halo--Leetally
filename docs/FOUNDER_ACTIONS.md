# Founder actions required before launch

Codex can implement the product, tests, migrations, safeguards, policy pages,
consent records and release documentation. The founder must complete or approve
the following external and legal decisions.

## Required facts

- [ ] Legal entity name and entity type
- [ ] Registered business address
- [ ] Privacy/grievance officer name and monitored email
- [ ] Security and billing support emails
- [ ] Governing city and state
- [ ] Minimum supported user age
- [ ] Interview, account, billing, security-log and backup retention periods
- [ ] Refund window and treatment of consumed speaking minutes
- [ ] Liability floor and insurance/counsel advice

## External accounts and approvals

- [ ] Apply Supabase migrations to the development project
- [ ] Supply production hosting and provider credentials through secret storage
- [ ] Complete Cashfree production KYC, webhook and refund configuration
- [ ] Own and verify the public domain for Terms and Privacy pages
- [ ] Create Chrome Web Store developer account and complete data-use disclosures
- [ ] Approve microphone, page-content and authentication disclosures
- [ ] Commission Indian counsel to review DPDP, consumer, tax, refund and Terms
- [ ] Sign required data-processing agreements with production providers

## Product validation only humans can supply

- [ ] Recruit 10-20 initial SDE-1 testers
- [ ] Obtain specific consent for any research/calibration dataset
- [ ] Recruit experienced interviewers to grade calibration sessions
- [ ] Decide the final hiring rubric and acceptable AI/human disagreement
- [ ] Approve pricing after observing actual provider cost per completed session

## Values that must be replaced before publishing

Search the legal documents for `[` to find all founder/counsel placeholders.
Do not publish either policy with unresolved placeholders.
